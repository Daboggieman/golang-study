# QuadChecker Project Requirements

You need to make a Go program called `quadchecker`.

What the program should do:

- It takes one string as its input argument.
- It checks whether that string is a "quad" function.
- If the string matches a quad, the program prints:
  - the name of the matching quad
  - and its dimensions.
- If the string does not match any quad, it prints:
  - `Not a quad function`
- Every output line must end with a newline character.
- If more than one quad matches, print all matches in alphabetical order.
- Separate multiple results with ` || `.

Required project files:

- `go.mod`
- `main.go`

The final folder structure should look like this:

```
quadchecker
├── go.mod
└── main.go
```
